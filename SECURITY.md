# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Best-effort security fixes |

iBridge is experimental software. Use it with this limitation in mind.

## Reporting a Vulnerability

Please do not publish security vulnerabilities in public issues.

Report them privately through [GitHub Private Vulnerability Reporting](https://github.com/adammg-tech/iBridge/security/advisories/new), if enabled for this repository.

If private reporting is unavailable, contact the repository owner privately through GitHub.

Please include the affected version, steps to reproduce the issue, and its potential impact.

## Response

Reports will be reviewed as time permits. Please avoid publicly disclosing a vulnerability before there has been a reasonable opportunity to investigate it.
